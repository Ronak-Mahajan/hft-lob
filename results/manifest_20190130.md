# Input manifest: NASDAQ TotalView-ITCH 5.0, 2019-01-30

`lob_replay` reads NASDAQ's public ITCH 5.0 sample file for 2019-01-30. The
file is not in this repository, in whole or in part. This manifest
identifies it exactly, so that a run can be repeated on a byte-identical copy.

- Source: NASDAQ's public ITCH sample directory,
  https://emi.nasdaq.com/ITCH/Nasdaq%20ITCH/, file `01302019.NASDAQ_ITCH50.gz`
- Format: ITCH 5.0 BinaryFILE. Each message is a 2-byte big-endian length
  followed by the message.
- Decompression: `gzip -dc 01302019.NASDAQ_ITCH50.gz > 01302019.NASDAQ_ITCH50`

| File | Bytes | SHA-256 |
|---|---:|---|
| `01302019.NASDAQ_ITCH50.gz` | 4,764,426,091 | `8c97b5b13bc451c012c2466fb7e258da134dab29aa47b67fe7b0088c78e870be` |
| `01302019.NASDAQ_ITCH50` | 11,245,883,092 | `1d0972ffc25b35902ccc3f9069aae517da56903d5795f872902b8697315f30c3` |

The SHA-256 of the decompressed file on disk equals the SHA-256 of the gzip
stream decompressed straight into `sha256sum`, so the file is a complete
decompression of the download. The commands and their output are in
[`manifest_20190130.log`](manifest_20190130.log).

## Reproducing the differential run

```bash
g++ -std=c++20 -O3 -march=native -DNDEBUG -Wall -Wextra -pthread -I include src/replay_main.cpp -o lob_replay
./lob_replay 01302019.NASDAQ_ITCH50 --differential
```

[`replay_20190130_differential.log`](replay_20190130_differential.log) is the
console output of that command, run from the directory holding the
decompressed file, on an Intel Core Ultra 7 265H laptop (Windows 11, 31.5 GB
RAM) with g++ 16.1.0 (WinLibs MinGW-w64 UCRT) and the Windows build line from
the README (the same flags plus `-static`).
